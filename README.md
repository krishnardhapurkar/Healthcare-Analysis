# Healthcare-Analysis
A Data Analytics project built using SQL, Excel, Tableau, and Power BI to analyze healthcare data and create interactive dashboards with KPIs like patient count, revenue, doctor workload, and treatment analysis.
# 🏥 Healthcare Analytics Dashboard

## 📌 Project Overview
The Healthcare Analytics Dashboard is an end-to-end Data Analytics project developed using **SQL, Excel, Tableau, and Power BI**. The project focuses on analyzing healthcare data to generate meaningful insights related to patients, doctors, treatments, hospital revenue, and lab reports through interactive dashboards and KPI tracking.

---

# 🎯 Objectives
- Analyze healthcare operational data
- Monitor hospital performance using KPIs
- Track patient visits and treatment costs
- Identify top diagnosed conditions
- Visualize revenue and doctor workload
- Build interactive dashboards for decision-making

---

# 🛠️ Tools & Technologies Used
- **SQL** → Data Extraction & Querying
- **Excel** → Data Cleaning & Preprocessing
- **Power BI** → Interactive Dashboard Development
- **Tableau** → Data Visualization & Insights
